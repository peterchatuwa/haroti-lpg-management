INITIAL SETUP (Run once)
================================================================================

1. Configure DNS A Record:
   Type: A
   Name: @
   Value: 169.58.127.129
   
2. SSH into VPS:
   ssh root@169.58.127.129

3. Update repository:
   cd /opt/haroti-lpg
   git pull origin cursor/domain-vps-setup-376b

4. Run SSL setup:
   cd /opt/haroti-lpg
   sudo bash scripts/setup-ssl.sh harotiholdingslimited.com admin@harotiholdingslimited.com

5. Configure firewall:
   sudo ufw allow 80/tcp
   sudo ufw allow 443/tcp
   sudo ufw allow OpenSSH
   sudo ufw enable

6. Access application:
   https://harotiholdingslimited.com
   https://harotiholdingslimited.com/api/docs


DAILY OPERATIONS
================================================================================

Connect to VPS:
  ssh root@169.58.127.129
  cd /opt/haroti-lpg

View running containers:
  docker compose -f docker-compose.prod.yml ps

View logs (live):
  docker logs haroti-web -f
  docker logs haroti-api -f
  docker logs haroti-postgres -f

View last 100 log lines:
  docker logs haroti-web --tail 100
  docker logs haroti-api --tail 100

Restart all services:
  docker compose -f docker-compose.prod.yml restart

Restart specific service:
  docker compose -f docker-compose.prod.yml restart web
  docker compose -f docker-compose.prod.yml restart api
  docker compose -f docker-compose.prod.yml restart postgres

Stop all services:
  docker compose -f docker-compose.prod.yml down

Start all services:
  docker compose -f docker-compose.prod.yml --env-file .env up -d

Check disk space:
  df -h

Check memory usage:
  free -h

Check system resources:
  docker stats


DATABASE OPERATIONS
================================================================================

Backup database:
  docker exec haroti-postgres pg_dump -U haroti haroti_lpg > backup-$(date +%Y%m%d).sql

Backup with timestamp:
  docker exec haroti-postgres pg_dump -U haroti haroti_lpg > backup-$(date +%Y%m%d-%H%M%S).sql

Restore database:
  docker exec -i haroti-postgres psql -U haroti haroti_lpg < backup-20260805.sql

Connect to database:
  docker exec -it haroti-postgres psql -U haroti -d haroti_lpg

List databases:
  docker exec haroti-postgres psql -U haroti -c '\l'

SSL CERTIFICATE MANAGEMENT
================================================================================

Check certificate status:
  sudo certbot certificates

Check certificate expiry:
  openssl x509 -in /opt/haroti-lpg/ssl/fullchain.pem -noout -dates

Test certificate renewal (dry run):
  sudo certbot renew --dry-run

Manual certificate renewal:
  sudo certbot renew
  sudo cp /etc/letsencrypt/live/harotiholdingslimited.com/fullchain.pem /opt/haroti-lpg/ssl/
  sudo cp /etc/letsencrypt/live/harotiholdingslimited.com/privkey.pem /opt/haroti-lpg/ssl/
  docker compose -f docker-compose.prod.yml restart web

View auto-renewal cron job:
  sudo crontab -l | grep certbot

TROUBLESHOOTING
================================================================================

Container not starting:
  docker logs haroti-web
  docker logs haroti-api
  docker logs haroti-postgres

Cannot connect to database:
  docker exec haroti-postgres pg_isready -U haroti
  docker logs haroti-postgres

Port already in use:
  sudo netstat -tulpn | grep :80
  sudo netstat -tulpn | grep :443

Check CORS settings:
  cat /opt/haroti-lpg/.env | grep CORS_ORIGIN
  (Should be: CORS_ORIGIN=https://harotiholdingslimited.com)

Clear all containers and volumes (WARNING: Deletes data!):
  docker compose -f docker-compose.prod.yml down -v --remove-orphans

Restart everything from scratch:
  docker compose -f docker-compose.prod.yml down
  docker compose -f docker-compose.prod.yml --env-file .env up -d --build

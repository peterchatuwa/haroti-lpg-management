================================================================================
TROUBLESHOOTING
================================================================================

DNS Not Resolving:
  1. Wait longer (can take up to 48 hours)
  2. Clear your DNS cache:
     Windows: ipconfig /flushdns
     Mac: sudo dscacheutil -flushcache
     Linux: sudo systemd-resolve --flush-caches
  3. Try different DNS server (8.8.8.8 or 1.1.1.1)

Still Can't Access:
  1. Check VPS firewall: sudo ufw status
  2. Verify Docker containers: docker ps
  3. Check nginx logs: docker logs haroti-web
  4. Verify SSL certificates: ls -la /opt/haroti-lpg/ssl/
